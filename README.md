# Sajid Portfolio — static site for GitHub Pages

Pages: `index.html` (Home), `wordpress.html`, `contact.html`
Styles: `css/style.css` · Images: `images/`

## Put it live on GitHub Pages
1. Create a GitHub repo named **`<your-username>.github.io`** (public).
2. Upload everything in this folder to the repo root (Add file → Upload files → drag the files and folders in → Commit).
3. Repo **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save.
4. After a minute the site is at `https://<your-username>.github.io/`.

## Images
Project screenshots and the logo load in full resolution from your Shopify CDN
(`cdn.shopify.com/s/files/1/0965/6965/5543/files/...`). Keep those files in
Shopify Admin → Content → Files. If one ever fails to load, the page
automatically falls back to the copy in `images/`.
